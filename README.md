# VIORE — Network Enthusiast

A responsive, static personal landing page with a restrained graphite/dark-grey palette, editorial typography, network topology graphics, project placeholders, and social profile links.

## Files
- `index.html` — content and page structure
- `style.css` — visual design and responsive layout
- `script.js` — mobile navigation and current year
- `README.md` — setup notes

## Important
The portfolio/project cards are clearly presented as planned learning areas/placeholders, not completed work. Replace them with real projects, descriptions, screenshots, and repository links as you build them. Do not publish confidential employer/client information or network diagrams without permission.

Social icons/links simply open public profiles; no social-media API or API key is required for that. Live feed integration would be a separate feature and may require platform developer access.

## Preview locally
Open `index.html` in a browser, or use VS Code with a local Live Server extension.

## Deploy on GitHub + Vercel
1. Create a repository such as `viore-portfolio` in GitHub.
2. Upload all four files to the repository root.
3. On Vercel, choose **Add New → Project** and import the GitHub repository.
4. Select `Other` as framework preset. No build command is required for this plain static site.
5. Deploy. Vercel's Git integration can create deployments from connected repositories and update them after pushes to the configured production branch. See the official docs: https://vercel.com/docs/git

Vercel's free-plan features/limits can change; check the current plan terms before publishing.
